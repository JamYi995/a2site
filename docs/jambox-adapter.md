# 果酱盒子接入适配计划

## 原则

先在独立仓库稳定协议，再让果酱盒子逐步改用开源模块。现网接口不直接复制到开源仓库，商业数据表和业务服务不外泄。

## 第一批映射

| 果酱盒子现有能力 | A2Site 模块 | 处理方式 |
|---|---|---|
| `WellKnownController` | `@a2site/protocol`、`@a2site/fastify` | 抽取中立清单，果酱盒子信息通过适配器注入 |
| Agent 反馈接口 | 反馈模块 | 保留流程，移除能力商店分类、JamBox 路径和数据库外键耦合 |
| 独立人类确认服务 | 人工确认模块 | 保留用户在场证明，业务审批载荷通过站点适配器提供 |
| Agent 身份凭证 | 身份模块 | 抽取作用域、轮换、撤销；邮箱和账号归属由站点适配器实现 |

## 不进入开源模块

- 专家入驻、作者委托和能力发布。
- Skill/MCP 制品、版本和审核。
- 报价、订单、付款、使用权和安装更新。
- 专家分成、结算、课程和服务器资源池。

## 接入完成标准

1. 果酱盒子的发现清单由 A2Site 协议生成。
2. 现有 Agent 客户端读取新发现入口后仍能进入果酱盒子原有机器方案。
3. PC、手机和外部 Agent 的关键链路通过回归测试。
4. A2Site 删除或停机不会破坏果酱盒子的商业数据库。
5. 果酱盒子专有接口不会被错误发布到通用清单。
